# Changelog

## 1.0.0

- Initial release of Let's Translate.
- Translate selected or entered text with Google, DeepL, or Youdao.
- Choose smart paragraph/list handling, whole-text translation, or line-by-line translation.
- Default to Vietnamese (`vi`) as the target language.
- Display results inline with configurable width, Unicode-safe wrapping, and timeout.
- Reposition results on editor scrolling without repeating translation requests.
- Keep the Output panel closed unless opened manually.
